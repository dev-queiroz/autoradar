API Tabela Fipe
Consulta marcas, modelos e preços na tabela Fipe de carros, motos e caminhões.

GET
https://api.invertexto.com/v1/fipe/brands/:type
Lista as marcas dos veículos.
PARÂMETROS
Nome	Valor	Tipo	Descrição
token *	
string	Também pode ser utilizado como Bearer token no header Authentication.
type *	
1
int	Tipo de veículo (valor 1 para carro, 2 para moto e 3 para caminhão).
Executar Limpar
REQUISIÇÃO

https://api.invertexto.com/v1/fipe/brands/1?token=SEUTOKEN

GET

Lista o histórico de preços de um veículo.

string	Código Fipe (pode ser encontrado na listagem de modelos).
year_id *	
string	Código do ano de um modelo (pode ser encontrado na listagem de anos).
